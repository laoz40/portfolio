## Project Overview

### What is Horus?

I built a web app to track my gym workouts. I decided to create my own because
I don't enjoy the existing solutions and my previous method of tracking
workouts (excel sheet) was extremely inefficient and didn't scale well.

I also did this for fun. I built this as a fun learning project, not a
vibe-coded app. I used AI as a teacher rather than a code generator because
understanding how things work matters to me. I wanted to build real skills and
stay relevant.
